# Source 11 — Reznikov Engineering / APEX

Checked 2026-09-20 using public first-party pages. No purchase, gated source download or proprietary code reuse.

The public [roadmap](https://reznikov-engineering.com/products) orders Interface, Open Loop, Humanoid, Closed Loop, and Build Review. Open Loop is advertised as six public parts covering conversation, voice and visible tools. Closed Loop is advertised as seventeen chapters for memory, scheduled work and verified actions, still marked forthcoming on the retrieved roadmap. The course and preview URLs returned no extractable chapter text; their internal implementation has not been verified.

The [APEX overview](https://reznikov-engineering.com/apex) describes a central coordinator directing specialists and names engineering, memory, design and quality roles. This is a public architectural description, not source-level proof of orchestration, permission handling or recovery.

The [APEX-UI repository](https://github.com/RubenM1990/APEX-UI) is an MIT orb/agent-graph interface with React/Next, SVG/CSS and a Three.js particle core. Its own README says interaction cycles visual states and excludes the Humanoid. Branding is excluded from the code license. KAIRO uses no copied UI code or assets.

The [Humanoid guide](https://reznikov-engineering.com/apex/humanoid) and [source-kit description](https://reznikov-engineering.com/apex/humanoid/buy) explicitly separate visual interface, artwork, animation and interaction from AI and voice. Publicly described features: a Three.js scene with about 300,000 points; assembly/birth; four moods; head depth and shading; optional finger tracking in a worker; breathing, backdrop and shockwave; microphone reaction demo. These are descriptions, not inspected internal algorithms. Creator, Commercial, Studio and Enterprise/OEM terms differ; none is an automatic open-source grant for the Humanoid.

## What KAIRO should learn from APEX

Use an observable event stream so the interface follows real work. Keep rendering, voice, inference and tool authority independent. A future specialist gets explicit scope rather than another unrestricted agent. Close the action loop with evidence. These strengthen KAIRO's boundary design; a humanoid or a large agent graph does not improve the first working AURORA task.
